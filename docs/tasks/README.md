# 작업 인계 기록

작업별로 `TEMPLATE.md`를 사용한다. 저장소 루트에서
`python .harness/run.py handoff task-id --title "작업 제목"`을 실행하면
현재 Git 상태를 넣은 새 파일이 생성된다. 기존 파일은 덮어쓰지 않는다.

기존 `.planning/STATE.md`나 이슈가 있으면 전체 진행 상태는 계속 그곳에 관리한다.
여기에는 해당 계획의 링크와 도구 전환에 필요한 검증·판단·다음 행동을 남긴다.
이미 열린 작업은 새 인계 파일을 계속 만들지 말고 기존 기록을 갱신한다.
끝난 작업은 상태를 완료로 바꾸고 기준 커밋/PR과 검증 결과를 남긴다.

인계 문서를 작성했다는 사실만으로 코드 변경이 완료된 것은 아니다.
